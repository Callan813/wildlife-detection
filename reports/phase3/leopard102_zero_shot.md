# Phase 3 model on LeopardID102 (another survey, no retraining)

Generated by `scripts/19_leopard102_zero_shot.py`. Gallery: 701 crops of 101 Zimbabwe leopards; 67 leopards have 2+ encounters and act as queries. Same-encounter matches removed, same flank only, top-k averaged per leopard. Night = capture hour >= 18:00 or < 6:00 (68% of crops).

| Model | Top-1 | Top-5 | Top-10 | mAP | Queries |
|---|---|---|---|---|---|
| DINOv2-S, untrained | 21.4% | 31.1% | 41.2% | 14.3% | 618 |
| **DINOv2-S + ArcFace (trained on Leopard ID 2022)** | 59.6% | 70.7% | 76.1% | 51.5% | 618 |
| ArcFace, night queries only | 60.5% | 71.5% | 77.3% | 51.5% | 425 |
| ArcFace, day queries only | 52.3% | 65.9% | 72.0% | 51.5% | 193 |
| ArcFace, flank rule off (any side can match) | 55.8% | 66.9% | 71.9% | 31.8% | 636 |
| DINOv2-S untrained, match must be at another camera | 4.9% | 13.6% | 20.6% | 6.2% | 467 |
| **ArcFace, match must be at another camera** | 42.7% | 59.1% | 64.5% | 40.1% | 467 |

Top-1 per leopard has a standard error of about ±6.0% with 67 query leopards. For comparison, on its own test set (107 Leopard ID 2022 leopards) the ArcFace model scores top-1 40.2%, top-5 57.1%, top-10 64.5%, mAP 35.4% (reid_finetune.md).

## Where the correct top-1 matches come from (ArcFace, main score)

- 394 correct top-1 matches: 66% from the query's own camera, 3% from the same day, 1% within 2 hours; median gap 14 days.
- So near-duplicates from one visit are not what drives the score, but a shared camera view is. The other-camera rows remove it.
